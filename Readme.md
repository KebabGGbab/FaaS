# FaaS

Это мой проект для лаболаторной работы в ВУЗе, представляющий собой пример сервиса FaaS.

## Постановка задачи

Необходимо разработать сервис, имитирующий работу облако с моделью FaaS. 
Сервис должен поддерживать работу с функциями, написанными на двух языках 
программирования: Python и C#. Пользователь должен иметь возможность загружать свои функции, 
удалять и запускать их. При запуске пользователь должен иметь возможность просмотреть вывод.
